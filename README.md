# studentmng

# This is a student database management systsem developed by postgreSQL. it showcases how data flows from different modules like department, course, and student

## Tabbles
    1. students-stores student info
    2. departments- stores department info
    3. courses- courses info
    4. enrolments- connects students to courses(many to many)
    5. lecturers- optional stores lecturers information
    6. course_lectures- links courses to lectures
